# C&C Tour Company website

## Build
- Replace the placeholder with an image-led travel homepage inspired by the reference site’s refined, spacious layout and warm natural palette.
- Add shared navigation and footer, plus dedicated Tours, About, and Contact pages.
- Use original safari and coastal imagery with clearly editable dummy tour names, descriptions, prices, and contact details.
- Make navigation, mobile menu, tour browsing, calls to action, and the enquiry form work cleanly across phone and desktop sizes.

## Visual direction
- Editorial East African travel aesthetic: ivory backgrounds, deep forest green, sun-warmed gold, restrained typography, and immersive photography.
- Use a large photographic opening scene, elegant serif display type, compact uppercase labels, and subtle scroll/hover motion.
- Preserve the reference’s premium calm and generous spacing without copying its content.

## SEO and safety
- Add unique titles, descriptions, social metadata, canonical paths, and relevant structured data to each public page.
- Use semantic HTML, accessible labels, sensible image attributes, and safe client-side form handling with no embedded secrets or unsafe HTML.
- Add a branded favicon and verify the finished pages and mobile layout in the live preview.

## Technical details
- React 19 and TypeScript with TanStack Start routing.
- Tailwind CSS v4 using semantic design tokens defined centrally in the global stylesheet.
- Local generated images bundled from the project assets folder.
